Connect to GitHub

A private repository's workflow runs are only visible to people with access to it, and anonymous access to a public one is limited to 60 requests an hour per network. Paste a GitHub token from your own account to load them in this browser.

  • Recommended: a fine-grained token limited to this one repository, with Actions: Read-only (Metadata: Read-only is added automatically), and a short expiry.
  • A collaborator on a repository owned by someone else's personal account can't target it with a fine-grained token — use a classic token with the repo scope and a short expiry instead.
  • The token is kept in this tab's session storage only — it is sent nowhere except api.github.com, and is forgotten when the tab closes or you click Disconnect.

Data comes live from the GitHub REST API (/actions/runs, /actions/workflows) and is computed in this browser; nothing is stored server-side. Durations are wall-clock, from the start of the latest attempt → completion. GitHub returns at most 1,000 runs per date-filtered query, and runs deleted by retention policy or by hand are gone from the API — longer history needs the persistence option in dashboard/README.md.
